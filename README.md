# LifeIsEndless

**Ecosphere** — a low-poly artificial-life sandbox: a living planet where plants and animals
grow from genomes, follow their own needs, evolve, and are shaped by weather, wind, currents,
and pressure across day/night cycles and seasonal quarters.

- 📄 Project brief: [`Docs/project-brief.md`](Docs/project-brief.md) — the single source of
  project context; every stage references it. Do not modify it without a design review.
- Development proceeds stage by stage (see "Stage sequence" in the brief). Each stage ends
  with: compiles, tests pass, acceptance criteria met, performance budget respected, README
  updated, tagged commit.
